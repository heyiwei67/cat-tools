使用说明

下面按平台整理安装与使用步骤。

一、电脑（Windows / macOS）

  1. 下载客户端：Windows 用 Clash Verge 或 v2rayN；macOS 用 Clash Verge 或 Stash。
  2. 复制本页「一键导入」里的 （需口令查看） 链接。
  3. 客户端里选「从剪贴板导入」，节点会出现在列表里。
  4. 开启「系统代理」（或 TUN 模式），浏览器即可翻墙。

二、安卓手机

  1. 安装 v2rayNG 或 Clash Meta for Android。
  2. v2rayNG：右上角 + → 「从剪贴板导入」→ 粘贴链接。
  3. Clash Meta：配置 → 新建 → 粘贴 YAML 或导入文件。
  4. 点右下角启动，首次会申请 VPN 权限，允许即可。

三、iPhone

  1. 安装 Shadowrocket（需要外区 Apple ID）。
  2. 右上角 + → 类型选 VLESS，按下表填写参数。
  3. 保存后点节点右侧开关连接。

五、打不开怎么办

  • TikTok / YouTube 打不开：检查客户端是否连上、系统代理是否开启。
  • 某个网站提示 502 / 000：它可能本身就在 Cloudflare 上，应设为直连。
  • 全部网站都打不开：客户端没启动或代理端口没开，重启客户端再试。
  • 速度慢：免费公共节点人数多会变慢，换一个节点或稍后再试。

节点 2 · 免费节点（X / Twitter / ChatGPT / Grok / Discord 用它）

（需口令查看）
  1. 安装 v2rayNG。
  2. 复制「节点 1」链接 → v2rayNG 右上角 + → 「从剪贴板导入」。
  3. 再复制「节点 2」链接，同样导入一次。

记住这条规则：TikTok / YouTube 选节点 1；上 X 或 ChatGPT 时切到节点 2。嫌麻烦就用 Clash Meta for Android，它可以按域名自动切换（配置见上方“内部资源”）。
